SCADAWATT v112 — Otomatik Google yorumları ve yatay kart akışı

KURULUM
Sunucuyu Ctrl+C ile durdurun. ZIP içeriğini mevcut proje klasörüne çıkartıp dosyaları
değiştirin. npm.cmd start çalıştırın; tarayıcıda Ctrl+F5 yapın.
npm ci veya build gerekmez. Mevcut data, .env, SMTP bağlantısı ve animasyon korunur.

GOOGLE BAĞLANTISI
Önceki Haritalar paylaşım bağlantısı tek başına yorumları çekmez.
Otomatik akış için Google Places API (New) gerekir.

1. Root → Yönetim → Google yorum entegrasyonu
2. Google Cloud projesinde Places API (New) ve faturalandırmayı etkinleştirin.
3. API anahtarı oluşturun; anahtarı Places API (New) ve sunucunun çıkış IP'siyle
   kısıtlayın. Sunucu çağrıları için web sitesi/referrer kısıtı kullanmayın.
4. Place ID bulucudan ScadaWatt işletmenizin Place ID bilgisini alın:
   https://developers.google.com/maps/documentation/javascript/examples/places-placeid-finder
5. API anahtarı, Place ID ve günlük istek üst sınırını girin; bağlantıyı açın.
6. Google bağlantısını kaydet → Yorumları test et.
7. SSS ve müşteri yorumları ayarlarında:
   - Yorum bölümünü göster
   - Google yorumlarını ve bağlantısını göster
   - Yorumları Google’dan otomatik çek ve kayan kartlarda göster
   seçeneklerini açın.
8. Taslağa uygula → Taslağı kaydet → mevcut root onay/yayın akışı.
   Mobil ve masaüstü içerik ayarları ayrı kalır.

API anahtarı yalnız root tarafından yönetilir; sunucuda şifrelenir.
data/google.key dosyası yeni şifreleme anahtarıdır; data klasörünü bütünüyle koruyun.
cms:backup bu anahtarı da yedekler. Anahtar kaybolursa API anahtarını yeniden girin.
Bu dosya .env veya SMTP anahtarınızı değiştirmez.
Windows'ta daha önce kullandığınız NODE_USE_SYSTEM_CA ayarı korunmalıdır.

GÖRÜNÜM
Google'ın döndürdüğü yorumlar yazar adı/fotoğrafı, yıldız, tarih ve Google
bağlantılarıyla yan yana gösterilir. Kartlar 4,5 saniyede bir yatay ilerler.
Üzerine gelince, klavyeyle odaklanınca veya elle müdahale edilince durur.
Duraklat/oynat, önceki/sonraki kontrolleri ve mobilde parmakla kaydırma bulunur.
Azaltılmış hareket tercihi etkinse otomatik kaydırma yapılmaz.
Uzun yorumlar genişletilebilir; Google'ın sıralaması ve puanları değiştirilmez.
Elle eklenen müşteri yorumları ayrı kartlarda korunur.

GOOGLE SINIRI VE MALİYET
Places API, Google'ın alaka sırasıyla seçtiği EN FAZLA 5 yorumu döndürür.
Bu yöntem bütün yorumları veya her zaman en yeni 5 yorumu döndürmez.
Google'da tüm yorumları gör bağlantısı işletme sayfasını açar.

API kullanımı Google Cloud kotasına/faturalandırmasına tabidir.
Ücretsiz kullanım veya belirli bir ücret garanti edilmez.
Sunucudaki günlük sınır (varsayılan 100 istek) ücret limiti değildir.
Google Cloud'da API kotası ve bütçe bildirimlerini ayrıca ayarlayın.
Kota günü UTC'ye göre değişir. Test çağrıları da günlük sınıra dahildir.
Yeni görünüm/yüklemelerde yorumlar otomatik alınır; sürekli API sorgusu yapılmaz.
Bölüm görünmeden Google isteği başlatılmaz. Aynı anda gelen eş istekler birleştirilir.
Yorumlar veritabanına/kalıcı önbelleğe yazılmaz, HTTP yanıtı no-store kullanır.

DİĞER
Google Maps'in resmi açık/koyu logo dosyaları ve yazar/kaynak bağlantıları eklendi.
Gizlilik açıklamaları güncellendi; kullanım koşulları ve Google politika bağlantıları
eklendi. Şirketin yayın öncesi hukuki kontrolünün yerine geçmez.
Google anahtarı verilmediği için gerçek işletmenin canlı yorumları burada denenmedi;
API akışı kontrollü yanıtlarla test edildi. Root panelinden gerçek bağlantıyı test edin.
